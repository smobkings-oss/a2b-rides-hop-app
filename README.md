# A2B Rides Rider App

Premium ride-hailing app for riders to book **instant** or **scheduled** rides.

## Features
- Instant ride requests with live price estimate
- Scheduled rides with date/time picker
- Mock driver matching
- Ride history (persisted in localStorage)
- Profile management
- Black / Gold / Holographic branding
- Fully responsive (mobile-first)

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide icons

## Local Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment
Deployed on Vercel. This is an MVP frontend demo. Connect to Supabase + Stripe + Maps for production.

## Branding
- Primary: Black
- Accents: Gold (#D4AF37 / #F4C430)
- Holographic gradients for premium feel
- Focused on NW Ohio launch
